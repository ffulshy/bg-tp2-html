2. Naissance du Web — Tim Berners-Lee et premières implémentations

1989-1991 — Tim Berners-Lee au CERN : HTML, HTTP, URL

Tim Berners-Lee propose au CERN un système pour partager des documents en utilisant l'hypertexte et Internet.

Il invente trois technologies fondamentales :

  • HTML (HyperText Markup Language) : langage pour structurer les documents
  • HTTP (HyperText Transfer Protocol) : protocole de transfert
  • URL (Uniform Resource Locator) : adresse unique d'une ressource

1993-1994 — Premiers navigateurs graphiques : Mosaic et Netscape

Le navigateur Mosaic (1993) popularise l'affichage graphique et les images.

Conséquence : l'arrivée de Mosaic et de Netscape rend le Web accessible au grand public.

1994-1996 — Standardisation et premiers moteurs de recherche

Le W3C est fondé pour standardiser les technologies du Web.

3. Le Web sémantique, Linked Data et Solid

Le Web sémantique : objectifs et concepts

L'objectif est de rendre le Web compréhensible par les machines pour qu'elles puissent traiter automatiquement le sens des données (RDF, OWL, SPARQL).

Linked Data

Le Linked Data est un ensemble de principes pour publier des données liées sur le Web.

Solid (Social Linked Data)

Le Web a été conçu comme un espace ouvert. Tim Berners-Lee a inventé Solid pour redonner aux utilisateurs le contrôle de leurs données personnelles.

Ce que ces trois thématiques ont en commun

Un point commun est l'ambition de faire du Web un espace de connaissances structurées et accessibles.

4. Résumé & dates clés

Synthèse chronologique

De l'idée visionnaire du Memex de Vannevar Bush en 1945 à la création du World Wide Web par Tim Berners-Lee au CERN en 1989, l'histoire d'Internet est celle d'une volonté constante de relier l'information.

Si les années 90 ont été marquées par la démocratisation (Mosaic, Netscape) et la standardisation (création du W3C), le Web d'aujourd'hui se tourne vers plus d'intelligence (Web sémantique) et de contrôle pour l'utilisateur (Solid).
